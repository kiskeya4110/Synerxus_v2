## 📋 Universal Quick Actions

### Common Tasks Across All User Types

| Task | Volunteer | Organization | Corporate |
|------|-----------|--------------|-----------|
| **Update Profile** | Settings → Profile | Settings → Org Profile | Settings → Company |
| **View Dashboard** | Dashboard (home) | Dashboard | Dashboard |
| **Check Messages** | Top nav → Messages | Top nav → Messages | Top nav → Messages |
| **Get Help** | ? icon → Help Center | ? icon → Help Center | Contact Success Manager |
| **Export Data** | Impact → Export | Reports → Export | Reports → Export |

### Keyboard Shortcuts (Desktop)

| Shortcut | Action |
|----------|--------|
| `G` then `D` | Go to Dashboard |
| `G` then `P` | Go to Projects/Profile |
| `G` then `M` | Go to Messages |
| `?` | Open Help |
| `/` | Search |
