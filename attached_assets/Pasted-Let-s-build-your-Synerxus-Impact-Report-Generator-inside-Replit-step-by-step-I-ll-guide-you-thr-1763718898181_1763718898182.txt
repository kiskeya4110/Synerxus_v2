## 🧠 Step 3: Backend Logic (JavaScript)

Create a file called `script.js` and paste this:

```javascript
document.getElementById("reportForm").addEventListener("submit", function(e) {
  e.preventDefault();

  const formData = new FormData(e.target);
  const data = Object.fromEntries(formData.entries());

  const report = `
    ## Synerxus Impact Report

    **Project Title**: ${data.title}  
    **Reporting Period**: ${data.date}  
    **Locations Served**: ${data.locations}

    ### Executive Summary  
    This report summarizes the impact of ${data.title}, highlighting contributions aligned with the SDGs.

    ### Key Metrics & SDGs  
    ${data.metrics}

    ### Stories from the Ground  
    ${data.stories}

    ### Corporate CSR/ESG Alignment  
    ${data.csr}

    ### Customization  
    - **Target Audience**: ${data.audience}  
    - **Tone**: ${data.tone}  
    - **Impact Focus**: ${data.focus}

    ### Next Steps  
    Continue scaling impact and engaging stakeholders through Synerxus.
  `;

  document.getElementById("output").innerText = report;
});
```
