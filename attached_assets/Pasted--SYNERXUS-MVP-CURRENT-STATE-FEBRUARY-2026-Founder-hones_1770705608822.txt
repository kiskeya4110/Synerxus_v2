## **SYNERXUS MVP — CURRENT STATE (FEBRUARY 2026)**  
*Founder-honest summary of what exists today—not roadmap aspirations*

---

### **WHAT IT IS**  
A B2B SaaS platform that captures **NGO-verified volunteer outcomes**—not self-reported hours—to generate audit-ready impact data for corporate ESG reporting. Built as a single codebase with **role-based views** (not three separate dashboards):

| User Type | What They See | Core Action |
|-----------|---------------|-------------|
| **NGO** | Verification queue + "Post Project Need" button | 1-tap confirmation of outcomes via app *or SMS* |
| **Volunteer** | Curated project matches + outcome logging form | Logs what they delivered ("Built financial dashboard") |
| **Corporation** | Read-only dashboard of verified outcomes + CSRD report generator | Views NGO-confirmed data with full audit trail |

---

### **CORE LOOP (THE ONLY THING THAT MATTERS)**  
```
Volunteer completes work 
  → Logs outcome ("Built dashboard for donor reporting") 
  → NGO receives push notification *or SMS* 
  → NGO taps "Confirm" (≤15 seconds) 
  → System captures: timestamp, device ID/SMS number, outcome text 
  → Auto-maps to UN SDGs 
  → Generates: (a) audit trail for corporation, (b) branded PDF for NGO fundraising
```

**This loop is functional today.** Everything else is scaffolding.

| Feature | Status | Critical Constraint |

### **THE SILENT PILOT PROBLEM (REALITY CHECK)**

- They were asked to *do work* (onboard staff, post projects) *before* seeing value  
- "Active partner" ≠ "verifying outcomes weekly"  

**Current fix:**  
- You manually draft their first project need → they only click "Publish"  
- You create their account → they only confirm staff list  
- First verification auto-generates branded PDF → immediate value ("This helps my fundraising")  

*Until verification rate hits 75%, no new features. Only friction removal.*

### **WHY IT MATTERS NOW**  

EU CSRD enforcement begins April 2025. Auditors are already rejecting self-reported volunteer hours as "unverifiable." Synerxus is the only platform where:  
- NGOs—not corporations—own verification  
- Verification works on basic phones via SMS  
- Every tap creates an audit trail satisfying ESRS S4 (communities)  

This isn't a "nice-to-have" feature. It's regulatory risk mitigation with a hard deadline.
