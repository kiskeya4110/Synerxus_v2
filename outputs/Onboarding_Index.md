### Core Value Propositions

| User Type | They Provide | They Receive |
|-----------|--------------|--------------|
| **Volunteers** | Time, Skills, Passion | Impact credit (AIUs), Rewards, Recognition |
| **Organizations** | Programs, Verification | Talent pipeline, Funding, Reporting |
| **Corporations** | Funding, Employees | ESG compliance, Impact data, Engagement |

### Key Platform Metrics

| Metric | Description | Tracked By |
|--------|-------------|------------|
| **AIU** | Verified impact units | All users |
| **Match Score** | Volunteer-opportunity fit | Volunteers, Organizations |
| **Trust Score** | Reliability rating | All users |
| **Syner-G Points** | Gamification rewards | Volunteers |
| **Hours** | Volunteer time contributed | All users |
