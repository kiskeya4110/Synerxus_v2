## Step 3: Funding Model Selection

### 3.1 Understanding Funding Models

Synerxus supports two primary funding approaches:

```
┌─────────────────────────────────────────────────────────────┐
│                   FUNDING MODELS                             │
├───────────────────────────┬─────────────────────────────────┤
│       BOUNTY MODEL        │      RETROACTIVE MODEL          │
│     (Pay-for-Goals)       │    (Pay-for-Outcomes)           │
├───────────────────────────┼─────────────────────────────────┤
│ • Pre-funded impact goals │ • Pay after verified results    │
│ • Funds held in escrow    │ • Lower upfront commitment      │
│ • Released on milestones  │ • Higher scrutiny per claim     │
│ • Best for: Known needs   │ • Best for: Flexible goals      │
└───────────────────────────┴─────────────────────────────────┘
```

### 3.2 BOUNTY Model (Pre-Funded Impact)

**How it works:**

1. You define a goal: "Educate 1,000 students in STEM"
2. Allocate funding: $50,000
3. Funds held in Synerxus escrow
4. Partner organizations deliver programs
5. Verified impact unlocks funding in tranches
6. Remaining funds returned or rolled over

**Best for:**
- Predictable CSR budgets
- Board-approved initiatives
- Multi-year commitments
- High-visibility programs

**Example:**
```
Bounty: "Climate Education Initiative"
Goal: Train 500 teachers in climate curriculum
Budget: $75,000
Release Schedule:
  • 25% on partner selection ($18,750)
  • 25% at 100 teachers trained ($18,750)
  • 25% at 300 teachers trained ($18,750)
  • 25% at 500 teachers trained ($18,750)
```

### 3.3 RETROACTIVE Model (Pay-for-Outcomes)

**How it works:**

1. Define impact you'll fund: "We pay $50 per verified student tutored"
2. Approve partner organizations
3. Partners deliver programs with own resources
4. Submit partner-confirmed evidence claims
5. You review and reimburse for verified outcomes

**Best for:**
- Outcome-focused programs
- Testing new partnerships
- Flexible budget allocation
- Results-based accountability

**Example:**
```
Retroactive: "Skills-Based Volunteering Impact"
Rate: $25 per volunteer hour verified
Cap: $100,000 annual
Eligible: Partners with Trust Score 80+
Verification: Photo evidence + GPS required
```

### 3.4 Hybrid Approaches

Most corporations use a mix:

| Program Type | Funding Model | % of Budget |
|--------------|---------------|-------------|
| Flagship initiatives | Bounty | 50% |
| Employee volunteering | Retroactive | 25% |
| Emergency response | Retroactive | 10% |
| Innovation grants | Bounty | 15% |

> 💡 **Pro Tip:** Start with 70% Bounty / 30% Retroactive. Adjust based on partner performance data!

## Step 4: Setting Funding Priorities

### 4.1 Creating Funding Priority Areas

[SCREENSHOT: Funding Priority Configuration]

Define distinct funding priorities:

| Field | Description | Example |
|-------|-------------|---------|
| **Priority Name** | Internal label | "APAC Education Initiative" |
| **Description** | Goals and scope | "Improve STEM education access in Southeast Asia" |
| **Annual Budget** | Allocated amount | $250,000 |
| **SDG Focus** | Aligned goals | SDG 4, SDG 10 |

### 4.2 SDG Focus per Priority

Each priority can target specific SDGs:

```
Priority: "Climate & Environment Portfolio"
├── SDG 13: Climate Action (60%)
├── SDG 7: Clean Energy (25%)
└── SDG 15: Life on Land (15%)
Budget: $500,000
```

### 4.3 Geographic Preferences

| Region Type | Examples | Considerations |
|-------------|----------|----------------|
| **Global** | Worldwide | Maximum reach, complex oversight |
| **Regional** | APAC, EMEA, Americas | Aligned with business presence |
| **Country** | Specific nations | Community investment, supply chain |
| **Local** | HQ area | Employee engagement, visibility |

### 4.4 Partner Criteria

Set minimum requirements for funded partners:

| Criteria | Options | Recommendation |
|----------|---------|----------------|
| **Organization Type** | NGO, Nonprofit, Social Enterprise | Based on program goals |
| **Minimum Trust Score** | 0-100 | 70+ for new, 60+ for established |
| **Verification Level** | 1, 2, 3 | Level 2+ for funding |
| **Track Record** | Projects completed | 3+ for significant funding |
| **Geographic Presence** | Required regions | Match to priority areas |

### 4.5 Verification Requirements

Define what evidence you require before releasing funds:

| Evidence Level | Requirements | When to Use |
|----------------|--------------|-------------|
| **Standard** | Activity log + org verification | General programs |
| **Enhanced** | + Photo/video evidence | Visibility initiatives |
| **Rigorous** | + GPS/QR verification | High-value, sensitive |
| **Audit-Ready** | + Third-party validation | Regulatory compliance |

> ⚠️ **Common Mistake:** Setting verification too high for all programs. Reserve "Rigorous" for high-value initiatives to avoid partner fatigue.

### 6.4 Funding Disbursement Triggers

Configure what releases funding:

| Trigger Type | Description | Use Case |
|--------------|-------------|----------|
| **Milestone** | Specific goal achieved | Project-based |
| **Time-Based** | Monthly/quarterly release | Ongoing support |
| **Impact-Verified** | AIUs generated | Pay-for-outcomes |
| **Manual** | CSR team approval | High-value, exceptions |

**Example Configuration:**
```
Partner: Education First International
Funding Model: Bounty ($100,000)
Disbursement:
  • $25,000 on contract signing (Manual)
  • $25,000 at 500 students enrolled (Milestone)
  • $25,000 at 1,000 verified AIUs (Impact)
  • $25,000 on project completion (Milestone)
```

> ⚠️ **Common Mistake:** Disbursing 100% upfront. Milestone-based releases create accountability!
